## 🛠️ How to Use

1. Download the `.ass` or `.srt` file from this repository.
2. Place the subtitle file in the same folder as the video file.
3. Ensure the video file and subtitle file have the exact same name (e.g., `Episode_01.mp4` and `Episode_01.ass`).
4. Play the video using a media player that supports custom subtitles (such as VLC Player, MPC-HC, or video editors like Wondershare/CapCut).
